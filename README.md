# 我的小卡册

一个个人使用的 K-POP 小卡收藏管理网站。未登录时数据保存在当前浏览器；登录同一邮箱后可同步到手机和电脑。

## 打开方式

线上网址发布后，直接用手机 Safari 或电脑浏览器打开网址即可使用。第一次打开后，在 iPhone Safari 点“分享”→“添加到主屏幕”，就能像 App 一样打开。

点右上角“登录同步”，输入邮箱并打开邮件里的登录链接。首次登录时，如果云端还没有数据，会显示“上传这台设备的本地数据”；确认后才会上传。小卡资料和图片按账号私有保存，网页公开不等于数据公开。

未登录的数据仍保存在当前浏览器。建议在上传前先做一次“完整备份”。

## 备份

首页的“导出表格”会下载 CSV 文件，用 Excel、Numbers 或 WPS 打开即可查看、筛选和编辑。表格包含小卡资料与“有图片”标记。

修改表格后，点“导入表格”选择 CSV 文件即可更新或新增小卡。请保留末尾的“系统编号（勿改）”列；已有小卡会按该编号更新，照片会保留。删除某一行不会删除网站中的小卡；如需删除，请在网站内编辑该卡后删除。

“完整备份”会下载 JSON 文件，其中包含小卡、图片和已保存的四宫格，适合留作恢复用的备份。
